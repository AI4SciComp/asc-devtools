## [0.1.0] - 2026-07-19

### Added

- Bash-only `asc` CLI with modular strict-mode runtime libraries.
- Configuration, doctor, GitHub discovery, clone, status, safe sync, and CMake
  preset workflows.
- Copy-based installer, exact-file uninstaller, and local Bash completion.
- Offline self-contained Bash tests and Ubuntu CI quality checks.

### Changed

- Moved the former Python implementation to `legacies/python`; it is no longer
  part of the active runtime or CI.
